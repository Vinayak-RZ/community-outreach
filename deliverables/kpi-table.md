## Actions that close each gap before the review
| Gap | Action | KPI |
|---|---|---|
| Consent sheets | Re-contact the reachable interviewees and get dated signatures, one by one (not in bulk). List who couldn't be reached | Reach |
| Contact log | One row per interview (I01–I36): date, place, role, interviewer, file, consent | Reach |
| Field diary + person-hours | Rebuild from the chat and file timestamps: date, place, members, start–end. Each member confirms their own rows | Depth |
| Hotspot map | One dated evening walk on 3–4 routes with geotagged photos, a dog count and ear-notch yes/no | Record |
| Hospital / admin data | Written request to the CMO and Security for monthly bite cases, vaccine doses (2 years) and sterilisation records. Record a refusal too | Record |
| Acknowledged submission | 2-page findings note (from `synthesis.md`) plus the poster to CCF and the Chief Warden; get a dated acknowledgement | Output |
| Written change | Ask one warden or CCF for one small commitment (R1 or R2) and get it confirmed by email | Change |
