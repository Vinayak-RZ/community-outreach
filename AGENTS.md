# Guidance for agents working in this repo

This repository is the compilation home for an EEC 399 Community Outreach project (campus dogs study, IIT Roorkee). Push small text and structured artefacts directly to `main`. Do not open PRs unless asked.

## Rules

1. **Never invent quotes, numbers, KPIs, interview content, or dates.** If a fact is not in a file under this repo (or a linked Release asset), say so and stop.
2. **Cite sources.** When you state a finding, point at the file path (and line or section if useful) it came from under `source/`, `interviews/`, `evidence/`, or `course/`.
3. **Large media belongs in Releases.** Do not commit files over ~20 MB, or large photo/video bundles, into git. Bundle them, attach them to a GitHub Release, and leave a short note in the matching folder naming the release and asset.
4. **Privacy.** The repo is private (since 19/10/2026) and `source/` holds raw team material with real names. Keep it internal: never make the repo public or share raw material outside the team. In analysis, deliverables and anything that could reach the poster, use roles and codes instead of interviewee names unless written consent covers publishing them.
5. **Honesty over polish.** The course grades primary contact and evidence a sceptic would accept. Record gaps and failed attempts; do not fill them with plausible fiction.

## Layout reminder

- `course/` — fixed course materials
- `source/` — raw chat and shared inputs
- `interviews/` — notes/transcripts
- `evidence/` — consent, diary, photo/video pointers
- `analysis/` — derived work
- `deliverables/` — poster, KPI table, submissions
